# Roadmap — Soups Unified Launcher (SUL)

This is a staged priority list, not a promise that every item is feasible. Update status only when supported by evidence.

1. Foundation: app shell, navigation, theme tokens, storage, manifests, logging/recovery, safe file operations, security basics, tests.
2. Build management: import/verify, original/optimized/experimental variants, rollback; HD2 7.1.1 isolation research.
3. Mod management: profiles, ownership-aware deploy/purge, dry-run, conflicts, backup/recovery.
4. Mod Builder: one real adapter path, then audio, Bink/RAD Video, patch workflow, Blender.
5. Modpack export/sharing, scanning/quarantine, provenance and licensing.
6. Diagnostics, compatibility matrix, measured profiling.
7. Social/networking foundations and supported Discord integration.
8. Capture/clipping with supported Medal.tv integration.
9. Remote play and host-controlled manual controller handoff.
10. News and update monitoring.
11. Emulator adapters and tested features.
12. Deferred: save transfer, broader publishing APIs, DMs, advanced game-specific integrity adapters, Steamworks replacement, relays, emulator-engine development.

Theme/rebranding hooks and security fundamentals start in Stage 1. Advanced multiplayer replacement remains research, not a committed feature.
