# Soups Unified Launcher (SUL) — AI Handoffs

This folder is the dedicated handoff area for work related to the Soups Unified Launcher repository.

## Purpose
- Store requirements, implementation handoffs, review findings, and status notes intended to be shared between ChatGPT and Claude.
- Keep these documents separate from the SUL source repository.
- Treat handoff documents as guidance; verify current repository state before acting on them.

## Working rules
- ChatGPT's role is read-only review of the SUL source repository unless the user explicitly authorizes a specific change.
- Do not modify SUL source code from this handoff repository.
- Do not assume Claude automatically checks this folder after each change; that requires Claude's environment or workflow to be configured to read it.
- Keep handoff documents focused, dated when appropriate, and clear about confirmed facts versus proposals or unresolved questions.
